# 翻譯 Ado 的歌詞（日文 → 繁體中文）

這是 Ado 應援指南網站用的中文翻譯，會跟著 MV 一句一句顯示在日文下面。請照下面的規則翻：

- 繁體中文、台灣用語。
- 短，像歌詞，不要解釋、不要加註。
- 日文用空白分成幾段的，中文也用空白分開；句尾不加句號。
- 英文歌詞照抄英文。擬聲詞、喊聲（例如「Hey」「ああ」）照聲音寫，不硬翻意思。
- 漢字後面括號裡的讀音（例如「模(かたど)る」的「かたど」）只是讀法，不用翻出來。
- 有官方英文字幕的句子附在後面當參考，意思以它為準。
- 前後文要連貫：同一個意象前後用同樣的譯法。
