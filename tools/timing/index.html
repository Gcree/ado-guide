    鍵盤快捷鍵指南 (Hotkeys)

    按鍵 動作說明
    空白鍵 Space 打點記錄：把目前指針時間賦予選中句（自動扣除反應延遲），並自動跳至下一句
    Shift + 空白鍵 純播放 / 暫停：單純控制影片播放，不覆蓋選中句時間
    K 播放 / 暫停 影片
    Backspace 退回上一句：重新打點或校對
    ↑ / ↓ 切換上一句 / 下一句選取
    Enter 試聽選取句：從選取句開始時間的前 2 秒播放
    [ / ] 選取句微調 提早 / 延後 0.05 秒（按住 Shift：0.2 秒）
    數字鍵 1 ~ 7 應援動作切換：1:大合唱、2:喊聲、3:拍手、4:揮手、5:跳躍、6:手勢、7:安靜聽（支援多選批次標記）
    數字鍵 0 清除應援動作：清除當前選取句（或多選句）的所有動作標籤
    Ctrl + Z 復原 / 上一步 (Undo)：還原上一次的打點、微調、長度調整或分割動作
    Ctrl + Y / Ctrl+Shift+Z 重做 / 下一步 (Redo)：恢復被復原的操作
    Ctrl + D 複製句子 (Duplicate)：快速複製目前選取句為新句
    M 靜音 / 取消靜音 切換
    + / - 時間軸放大 / 縮小
    清單抓取拖曳 按住清單每行左側的 ⋮⋮ 手柄上下拖曳直接調整歌詞順序
    Alt + ↑ / ↓ 將選中句歌詞上移 / 下移一行（或點擊工具列 ⬆ / ⬇）
    Shift + 點選 連續多選：選取從上一句到點選句之間的所有歌詞區間
    Ctrl + 點選 加選 / 減選：個別加入或移出選取的句子
    空白處拉框 在字幕軌空白處拖曳拉出選取矩形，批次框選多段歌詞
    拖曳多選字幕 按住任一選中字幕塊拖曳，同時批次平移所有選中歌詞
    Ctrl + A 全選 所有歌詞進行批次移動或微調
    Delete 清除 選取句的時間打點
    C 切半分段 (Split)：將選中句切分為兩句，後半段自動插入為下一句
    拉動字幕右緣 在時間軸上直接滑鼠拖曳字幕塊的右邊緣，即可自由延長或縮短該句的顯示時間
    ← / → 或 J / L 倒退 / 快轉 2 秒（按住 Shift：5 秒）
    Home 時間軸與影片跳至曲首 00:00
    ✨ 效率強化
    G / Shift + G 跳到下一句 / 上一句未打點的歌詞，並把影片帶到前一句附近
    R 循環試聽選取句（含 0.5 秒前導），用 ↑↓ 換句時循環區間會跟著走；搭配 [ ] 微調
    , / . 播放指針 倒退 / 前進 0.1 秒（按住 Shift 改用 < > 調整播放速度）
    Shift + End 選到結尾：選取這句到最後一句，再用 [ ] 或拖曳整段平移（LIVE 版間奏變長時超好用）
    多選 + 輸入框 在時間輸入框打 +1.5 或 -0.8 後按 Enter，選取句全部一起平移
    E / N 編輯選取句 / 在後方新增一句
    Shift + Delete 刪除選取句（支援多選）
    Ctrl + S 下載 JSON
    彈窗內 Enter / Esc Enter 送出（貼上歌詞用 Ctrl+Enter）、Esc 關閉；彈窗開著時其他快捷鍵自動停用
    滑鼠滾輪 在時間軸上直接滾動 = 左右捲動；Ctrl / Alt + 滾輪 = 縮放
    時間軸拖曳 在時間軸刻度尺上拖曳指針或拖曳字幕塊直接調整位置
    ⚠️ 尚未讀取到歌曲資料庫 (songs.js / song-lyrics.js)。請確認靜態伺服器是在專案根目錄啟動。
