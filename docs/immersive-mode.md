# 沉浸模式設計

## 概念卡

| | |
|---|---|
| Idea | 沉浸模式就是你在 Ado 演唱會的座位：MV 是舞台大螢幕，歌詞是螢幕下方的字幕，畫面最下面是整片手燈海 |
| Metaphor | 演唱會場館：熄燈、舞台螢幕、字幕、台下的手燈 |
| Signature | 「交給觀眾」：播到大合唱的句子，舞台螢幕退暗、往後縮，歌詞發出這首手燈色的光，台下手燈海整片舉高；唱完螢幕再亮回來 |
| Emotion | 開演前場燈熄掉的那一秒 |
| Motion verb | 像場燈一樣「暗下、亮起」：慢進慢出，不彈跳 |
| Screenshot | 大合唱時：暗下來的舞台螢幕、置中發光的那句歌詞、底下整片同色的手燈 |

錨點：這個網站本來就有每首的手燈色（PEN）、拍點（BEAT）和逐行「大合唱」標記，這個概念只有應援指南做得出來。

其他兩個候選：
- 歌詞海報（大字置中、背景取 MV 主色）：跟一般音樂 App 的歌詞畫面一樣，可攜性太高，不選。
- 剪影箱（影片框成發光的箱子）：太依賴特定演出的舞台造型，不選。

## 系統

- **色彩**：場館黑 `#05060a`（底）、字 `#f4f6fb`、次要字 `rgba(244,246,251,.5)`、更淡 `rgba(244,246,251,.32)`、細線 `rgba(255,255,255,.08)`、強調色＝這首的手燈色 `--mesh-c1` / `--mesh-c2`（`updateAmbientColors` 設在 body 上）。
- **字**：沿用站上的日文字體。現在這句 700 字重、字距 -0.015em；其他句小一號、半透明。
- **形狀**：舞台硬體（螢幕）6px 圓角；介面（提示膠囊、頂欄）全圓膠囊。
- **動態**：進入時先熄燈（黑幕 260ms 淡入），換版面後黑幕 700ms 淡出，同時螢幕「開機」（從全黑、過亮再回正常）。離開時黑幕短暫淡入淡出，像場燈亮起。大合唱的退暗 1.1 秒進、1.4 秒出。
- **閒置**：暫停時舞台後方的光暈仍慢慢呼吸（14 秒一輪），不需要播放也看得出是活的。
- **減少動態**：沒有黑幕轉場、沒有螢幕縮放和開機動畫；大合唱時只把螢幕調暗。
