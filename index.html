演唱會前在家先練：看著 MV 跟歌詞，哪裡拍手、哪裡合唱、哪裡安靜聽 Ado 唱。不照任何一場的歌單，不會暴雷。

    認識 Ado

    第一次去也看得懂的幾個梗。

    • 藍玫瑰Ado 的視覺裡常出現玫瑰，演唱會的 dress code 也是玫瑰。戴一朵藍玫瑰去就很有氣氛。
    • 鯊魚尖牙Ado 的插畫形象有一口鋸齒狀的尖牙，粉絲畫 Ado 時常用它當記號。
    • 衣櫃錄音室Ado 長年在自家衣櫃裡錄歌，訪談和 MC 常提到。
    • 不露臉的舞台Ado 不公開長相，演唱會靠燈光、剪影和舞台裝置呈現。這也是全面禁止拍照的原因之一。
    • 名字的由來「Ado」取自日本傳統戲劇狂言裡的配角稱呼「アド」。
    • 從「歌ってみた」出發Ado 國中時開始在網路上投稿翻唱，2020 年以〈うっせぇわ〉正式出道，所以歌單裡也有很多 Vocaloid 翻唱。

    參加須知

    每場以主辦公告為準，以下是 Ado 演唱會一直以來的規矩。

    • 全面禁止拍照、錄影、錄音從進場那一刻開始就算，開演前也一樣。
    • 不能帶望遠鏡入場檢查會被收走。
    • 螢光棒以官方公告為準近年巨蛋場只能用最新的官方螢光棒，會跟演出自動連動，不用自己換色。開演前一晚先用 App 配對好。
    • Dress code 是玫瑰戴玫瑰飾品或穿玫瑰圖案的衣服，不是強制。
    • 喊聲與呼應主辦沒有禁止就可以，但不要蓋過 Ado，也不要影響旁邊的人。不確定時跟著現場氣氛。
    • 跳之前先看周圍前後左右留空間，螢光棒不要甩、不要丟。

      貼上歌詞與應援

      用 LRC 格式，一行一句：[00:47.20]日文歌詞 / 中譯。斜線後的中譯可以省略。

      漢字的讀音寫在後面的括號裡，例如 練習(れんしゅう)，假名會標在漢字上方。

      要標動作，在時間後面加大括號：[00:47.20]{sing,wave|一起唱}日文 / 中譯。動作有 sing（大合唱）、clap（拍手）、wave（舉手揮動）、jump（跳躍）、call（喊聲）、gesture（手勢）、listen（安靜聽），直線後面是要喊的字。段落標題寫成 [00:47.00]#副歌。

      貼好按「套用」，這首歌就換成你的版本，只存在這台裝置的瀏覽器。整理好後把文字交給我，我再放進正式網站。

      對時間工具：邊聽邊打點，產生 LRC／SRT

      1. 把正版歌詞貼在左邊，一行一句；要附中譯就寫成 日文 / 中譯，要標動作就在行首加 {sing,wave}，段落標題寫 #副歌（段落不用打點，會跟著下一句的時間）。

      2. 按「開始打點」，影片會從頭播放。每唱到新的一行就按一下「打點」或空白鍵；按錯了按 Backspace 退回一行。

      3. 打完右邊會產生 LRC 和 SRT。按「套用到這首歌」就能直接預覽，或複製下來保存。

      只想做應援提醒、不放歌詞？按「載入段落範本」，會依這首的應援重點列出前奏、副歌、間奏等段落。刪掉這首沒有的段落，再邊看 MV 邊在每段開頭打點。
